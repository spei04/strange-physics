# Private native/classical publication composition

This source unit composes retained evidence and returns a pure ledger append/CAS proposal.
It does not execute a study, measure work, persist files, certify numerical execution,
or establish MAP, selection-before-feedback, calibration or real comparison readiness.
All full evidence, material hashes, results and receipts are owner/evaluator-only.
They must not reach the online selector, even when a report has a public-safe shape.

## Actual material boundary

`reconcile_study_publication` calls `reconcile_native_study_score` itself: the complete
bounded ledger and actual SQLite Journal must contain all twelve charged/committed
purchases, no missing reservation or pending row, and the full failure-inclusive
prefix. It binds actual frozen pool/candidate/prediction/scoring material and private
catalog world, reconstructs the native context, and checks actual retained results
against distinct measured attempt envelopes.

The sixth material is the actual frozen `classical_diagnostic_config`. The adapter
reconstructs the classical input from the verified native context/world and this
bundle, checks the exact retained result with the existing classical binder, and
joins one distinct same-cell comparison reservation plus terminal full facts and
measurements. It does not relabel old prediction work as native work or settle
diagnostic child stages. Retained evaluation timing and detailed no-report failure
results remain intact. Deterministic protocol/preflight validation is allowed;
fit, prediction, reference generation and evaluator execution are not rerun.

Absent diagnostic work produces incomplete evidence. A reserved/running/unknown
attempt retains its actual reservation and every known measurement; retries do
not refund the first envelope. A present result requires terminal matching facts.
A terminal attempt without its result is a partial witness and fails closed.
If any diagnostic reservation exists, an omitted requested attempt ID cannot
hide it. A malformed or substituted result is an input failure, not a fabricated
scientific failure.

The native primary is independent of diagnostic success: a terminal rejected,
fit-failed, preparation-failed, unscorable or evaluator-failed diagnostic retains
its own stage result and does not erase a valid native score. Native unscorable
and no-report evaluator failure remain failed primary outcomes. Unknown/missing
work makes the outcome incomplete; cap-limited requires actual zero remaining
CPU/artifact capacity or retained overrun. Absence by itself is not budget evidence.
Every outcome retains an available original primary report.

## Proposal and replay

`propose_study_publication` checks a fresh expected revision and head, composes
actual material, then proposes one additive `StudyPublicationEvent`. It wraps
the unchanged `StudyCellOutcome` and a compact raw/canonical evidence reference.
Existing event variants, defaults and fifteen-role manifest bytes remain unchanged.
A legacy bare outcome cannot substitute for a publication evidence receipt.

The identity chain is acyclic:

1. Evidence binds the original pre-append raw/typed ledger and actual materials.
2. The event binds that evidence and its derived outcome.
3. The receipt binds the event, resulting record and resulting ledger identity.

Neither resulting record nor receipt is hashed back into its own evidence/event.
Exact replay supplies the original ledger bytes and original private evidence bytes,
proves that original ledger is the actual retained prefix immediately before the
event, validates the original actual material again, and returns the original
receipt. Unrelated later appends do not rewrite original costs or result timing. Current
capacity decisions must use the authoritative current ledger, never a replayed
receipt's historical budget snapshot.
The same event ID with changed diagnostic/raw material conflicts even when the
primary outcome metadata is unchanged. Missing/conflicting witnesses fail closed.

The returned ledger is only a proposal. The supervisor must authenticate storage,
hold quiescent Journal access, atomically compare revision/head, durably retain
original evidence/material and ledger together, and implement fsync/recovery and
process measurements. This slice contains none of those producers. Evidence and
artifact creation itself consumes the one cumulative accounting budget; a later
producer must reserve and measure its work, with no second allowance. A publication
seals the cell's outcome; unresolved attempts retain their charges and may still
be measured/finalized, but cannot silently turn the original receipt into a new one.

## Bounds and remaining scope

The existing strict per-message limits remain; complete compose inputs are capped
at 64 MiB before decoding, evidence at 32 MiB with depth 40 and two million nodes.
Raw and typed canonical identities remain distinct. External parser bounds do
not replace producer fetch-before-allocation or durable storage controls.

This boundary requires the existing native selected/prepared result and twelve
closed purchases. Earlier purchase/selection/preparation-unavailable publication
is explicit remaining parent work, served only by existing unfinished accounting
until a separately reviewed composition supports it. Both parent tasks remain
partial. Source tests use declared synthetic manifests and measured-cost fixtures;
they do not fabricate genuine later N02/N04/N03 evidence or add source dependencies
on those producers. Real comparison publication remains behind the genuine frozen
manifest/scientific gates and measured durable supervisor.
