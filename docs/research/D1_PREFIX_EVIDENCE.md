D1 nor establishes actual source execution, exposure completeness or scientific
qualification. The protocol and all old guards remain unchanged. A2's full
prefix/future binder, arithmetic evidence and M03-to-D03 witness are still being
authored and are not part of this first review checkpoint.

The pool constructor accepts only fixed count, public structure and physical
queries. It builds the uniform midpoint grid before it can accept observations.

## Conditional reference arithmetic

The existing oracle uses correctly rounded 100-digit Decimal exp/ln. An explicit
fresh context removes ambient precision, rounding and trap changes. Adjacent
representable Decimal values enclose each such result. This conditional property
must be bound to the actual pinned oracle source/runtime before scientific use;
the synthetic fake oracle deliberately does not establish it.

Machin/ODE inputs retain their existing absolute 1e-60 allowances. The constants
calculation treats sigma and 1/N as exact dyadic inputs and pi as uncertain. For
positive arguments, the mean-value bound
`abs(log(x)-log(y)) <= abs(x-y)/min(x,y)` propagates argument uncertainty without
another logarithm. Gaussian constants retain that interval, rather than silently
assuming their computed centers are exact.

For a full-prefix joint reference center z with an enclosure radius eta<1,
`1-eta <= exp(delta) <= 1/(1-eta)` for abs(delta)<=eta. Multiplying the exp-center
rounding enclosure by this positive relative interval encloses the actual weight.
Directed summation includes every weight; the same positive-sum log bound gives
the evidence enclosure. Subtracting the joint maximum enclosure gives the
centered normalizer. Normalized logs and probabilities use this same denominator.
This relative argument avoids over-amplifying the joint perturbation with a loose
absolute exp/sum/reciprocal chain. There are no additional exp/log calls.

Derived absolute joint/constant/evidence/normalized-log and relative emitted/
normalized-probability errors must fit the existing 1e-48 reference allowance.
A wider computed enclosure fails qualification; it never enlarges a tolerance.
The native endpoint/component gates and overlapping 3e-9 reserve are unchanged.
The finite-domain proof, actual source/counter joins and A2 integration still need
independent review and engineering checks.

## Training forecast bound and limits

For t=1/2, `f(k)=q cos(sqrt(k)/2)`, `abs(f)<=q` and `abs(f')<=q/8` on [0,4].
Midpoint radius 2/N contributes q/(4N); cell-mass TV delta contributes at most
2q delta. Add the actual endpoint allowance once. A prior uses exact uniform
masses and delta=0; a reused posterior must supply its own matched certificate.
This bound is not the t=3/4 predictive bound or a usefulness threshold. Exact
bounded rational feasibility sums reject mass deficits/excesses smaller than the
working Decimal precision. No recorded observation is needed to freeze the mean;
innovation formation is a separate operation after the caller retains it.

A1's source loops freeze endpoint, normalization and transcendental counts above.
Revalidation, canonical encoding/hashing, reference interval algebra and forecast
rational-sum costs are additional engineering/scientific work, not extra CPU
charges to add to a measured service total. The final full-success low-level and
retained-byte census is intentionally not declared complete here. The reference
values and native captures are actual material to retain/reconstruct, not merely
matching supplied hashes. Source/runtime attestation, report schema, output caps,
exposure decisions and execution allocation remain later gates.
