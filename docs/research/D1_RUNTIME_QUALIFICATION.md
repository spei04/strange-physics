# D1 protected runtime qualification

This is the engineering qualification of one capture-only path. It does not run the D1 scientific batch or establish production readiness. The downstream approved comparison remains 36 episodes / 432 experiment slots.

## Delivery and inputs

Integrate the independently reviewed source through the protected main workflow. Accept the candidate only after that same run passes required checks and its installed-wheel smoke. Bind the resulting main commit, workflow run/attempt, artifact digest, five retained candidate files (wheel, sdist, provenance, checksums and exact runtime requirements), lock and requirements export. Do not relabel an older candidate.

Use one private cloud installation from the pinned interpreter, locked runtime requirements and verified wheel. Preserve the exact final source export for runtime scripts/test helpers that the package deliberately excludes. Materialize the existing installation and protected-plan formats from those observed bytes. The materializer is not an authority issuer.

Verify complete stdlib, environment, package/dependency, interpreter-link and startup inventories, with only the reviewed Linux aliases. Use the genuine uv environment with a verified owned regular copy at bin/python before any consumers. The controller and target are distinct processes using that same isolated executable; preserve real uv configuration and sibling links. Reject missing provenance, requirements mismatch, unreviewed hooks, changed source or writable custody before capture.

## Ordered qualification

1. Complete the combined guarded fake-only software check on the final source. Retain original Unit19 as incomplete. Recheck changed bootstrap cases because the runtime-compatibility source changed, not to rewrite the earlier 80-case result.
2. Qualify the actual profile callback in three short, separately reaped benign children: retained Python code, fixed source-name route and unrelated C builtin len. No scientific primitive is a probe.
3. Use one fixed handshake to bind a running service invocation/cgroup, let its leader exit while a descendant remains alive, refuse completion, then release the descendant and prove terminal-empty accounting before stop and cleanup.
4. Start the fixed independent owner before the sole capture submission. Keep the original work cutoff and terminal deadline. All three complete inventory validations run inside the existing bounded service. A late start, lost acknowledgement, changed identity, guard violation or uncertain closure cannot become success.
5. Reconcile source/request/report identity, terminal cgroup accounting, parent/command accounting and every retained outcome. Keep overlapping CPU scopes distinct. Record missing measurements as unknown.

## Prospective engineering envelope

Local command partitions: source qualification 200 CPU / 600 active-wall seconds; acquisition/install 150 / 450; inventory, benign qualification and capture 200 / 600; closure 50 / 150. Total 600 CPU / 1,800 active-wall seconds. These are prospective command ceilings, not a whole-operation CPU measurement. Authoring, SSH/GitHub administration and provider dollars remain unmeasured.

Retained-output ceiling: 1 GiB, partitioned into 512 MiB installation, 128 MiB bootstrap temporary files, 16 MiB candidate bundle, 32 MiB source/control copies, 64 MiB evidence (32 MiB software and 32 MiB actual runtime), and 272 MiB failure reserve. Tighter existing per-file/inventory limits still apply. Actual source census and output bounds must fit before runtime starts.

Hosted integration CI and protected-main candidate are separate: 83 and 98 configured job-minutes respectively, not CPU or elapsed pipeline time. Existing CI smoke calls are ordinary software validation, separate from capture-only qualification.

Every attempt and failure is retained. No automatic runtime retry, transfer from a closed engineering account, change to frozen scientific limits or scientific launch follows this qualification. A failure triggers closure/reconciliation; a new attempt needs a concrete revised plan.
