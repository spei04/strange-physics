# Retained comparison stages

Checkpoint 1 adds strict comparison payloads and pure material binders for preparation, prediction and scoring. Existing supplied-material request and receipt schemas are unchanged. Checkpoint 2 connects these payloads to the existing fixed measured supervisor; its source and synthetic authority tests are under review, and measured runtime admission is still pending.

Preparation binds the complete twelve-row candidate history, including failed rows, to frozen pool, candidate configuration, scoring policy, prediction configuration and world-space identity. A supplied selected candidate is explicit fixed selection, not a MAP or selector claim. Prediction reconstructs the exact prepared probe and selected model. Scoring compares all 24 ordered, independently resolved attempt outcomes and the private frozen world. Deterministic preparation/protocol recomputation performs no numerical prediction or evaluation.

These pure binders do not authenticate SQLite closure rows, latest terminal states, Journal currency, installed code, source/lock identity, or observed missing/invalid transport. The retained resolver authenticates these authorities before invoking the pure binders during charged work. A retained valid result cannot be relabelled missing or invalid; an unavailable result cannot release its original unknown hold. Exact paid recovery must reuse original retained materials without producers or live input paths.

The proposed 45-call synthetic profile is arithmetic only: 978,165,760 bytes and 1,247 CPU seconds with a 1 MiB control database. Actual database fit, cumulative setup/copy bounds, remaining recovery/publication/finalization headroom and measured execution are pending. The prediction allowance assumes one retained input and one output, each at most 512 KiB; any additional persisted reconstruction or capture requires its own pre-write allowance. Publisher authority handoff, full-study admission and grid/Laplace work remain separate.


The resolver uses this store's original closure, separate ticket bytes and exact original reservation. A result requires the original attempt's terminal facts, receipt source and installed-build identity, retained raw input/output, and canonical producer validation. Failed or rejected typed results remain result transport. A consumed ticket alone is insufficient. Preparation resolves the full original candidate capture and frozen artifacts; prediction resolves the exact preparation, selected model and probe. Selection must precede any earlier same-cell native or classical evaluator reservation, including uncertain work.

Fresh scoring resolves all 24 original prediction attempts against its current ledger view. Missing output requires authenticated reserved/running/unknown work without facts, no closure and an actually absent deterministic output. Invalid output requires the same no-closure authority plus retained raw bytes whose parsing or exact input/result binding fails. A fully valid unclosed result is incomplete evidence and cannot be relabelled invalid or converted into a receipt. Filesystem, permission and store errors are failures, never missing transport.

Paid replay of a closed score uses that score's original receipt-bound ledger prefix. Its authenticated original missing witness is not re-observed in today's directory, and a later retry closure for the same logical prediction cannot replace the original attempt. Historical invalid transport still requires its original raw bytes and digest. Fresh scoring cannot hide a currently closed result behind that older unavailable label. No prior unknown hold is settled by scoring or replay.

The wrapper and reconstructed typed inputs are bounded in memory. The fresh prediction path retains exactly one wrapper input and one output; the resolver reads ancestors without copying them to new files. All read witnesses, including fresh output absence, are rechecked through the existing atomic closure. Synthetic SQLite tests exercise these joins and historical-view rules with poisoned producers; they are not actual purchased-history or public replay evidence.
